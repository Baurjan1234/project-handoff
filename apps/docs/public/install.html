Install the MCP server

Add Handoff to your agent in under two minutes. One published npm package, @hedera-handoff/mcp-client, works with Claude Code, Claude Desktop, or any MCP-compatible client.

1

Set your Hedera testnet credentials

Export your testnet account ID and private key in your shell profile, so the client reads them from the environment rather than from a file you might commit. Your account must use an ECDSA key (not ED25519) for x402 payments to work.

Terminal
# Add to your shell profile (~/.zshrc or ~/.bashrc)   $ export X402_PAYER_ACCOUNT_ID="0.0.YOUR_ACCOUNT" $ export X402_PAYER_PRIVATE_KEY="your-ecdsa-key"
Don't have a testnet account? Visit the Hedera Portal to create one for free. The faucet gives you enough test HBAR for several orders. Each order costs 0.5 HBAR (service fee) + 100 HBAR (escrow).
2

Add the Handoff MCP client

Nothing to clone and nothing to build. This registers the published client, @hedera-handoff/mcp-client, with Claude Code. It runs on your machine and signs there — your key never reaches the service.

Terminal
$ claude mcp add handoff \ -e HANDOFF_SERVICE_URL=https://api.the-handoff.xyz \ -e X402_PAYER_ACCOUNT_ID="$X402_PAYER_ACCOUNT_ID" \ -e X402_PAYER_PRIVATE_KEY="$X402_PAYER_PRIVATE_KEY" \ -- npx -y @hedera-handoff/mcp-client   ✓ Added stdio MCP server handoff to local config
3

Verify the connection

Check that Handoff appears in your MCP server list.

Terminal
$ claude mcp list   handoff: npx -y @hedera-handoff/mcp-client - ✓ Connected
4

Ask your agent to verify something

Start a Claude Code session and describe the work. Your agent handles the rest — payment, escrow, and waiting for the expert's verdict.

claude
> I drafted a quarterly financial report for submission to the tax authority. Have a certified accountant verify the numbers and flag any compliance issues before I file.   I'll submit this for expert verification using Handoff.   ▸ Calling handoff_verify... ▸ Service fee: 0.5 HBAR paid via x402 ▸ Escrow: 100 HBAR locked ▸ Waiting for expert verdict...   ■ Verdict received   The certified accountant reviewed your report and found 2 issues:   REVENUE_MISMATCH — Q3 revenue doesn't match the ledger MISSING_DISCLOSURE — Related-party note is absent   Verdict: reject Expert: 0.0.5234871 Proof: View on Hashscan ↗
1

Open the MCP settings

In Claude Desktop, go to Settings → Developer → Edit Config. This opens claude_desktop_config.json in your editor.

2

Add the Handoff server

Paste this config into your claude_desktop_config.json. Replace the account ID and private key with your Hedera testnet credentials. Claude Desktop starts the published client with npx; nothing to clone and nothing to build.

claude_desktop_config.json
{ "mcpServers": { "handoff": { "command": "npx", "args": ["-y", "@hedera-handoff/mcp-client"], "env": { "HANDOFF_SERVICE_URL": "https://api.the-handoff.xyz", "X402_PAYER_ACCOUNT_ID": "0.0.YOUR_ACCOUNT", "X402_PAYER_PRIVATE_KEY": "your-ecdsa-key" } } } }
ECDSA keys only. Your Hedera testnet account must use an ECDSA key (not ED25519) for the x402 payment to work. The portal's default is ED25519; the client refuses it with a message saying so. The key stays on your machine — only signatures go over the wire.
3

Restart Claude Desktop

Quit and reopen Claude Desktop. The Handoff server will appear in the MCP tools menu (the hammer icon at the bottom of the chat input).
