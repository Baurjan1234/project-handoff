# Brief bumped to v2

**Decision.** `docs/project-brief-v2.md` is the source of truth for scope.
`project-brief-v1.md` stays in the repo as history and is no longer authoritative.

**Why.** The versioning rule set this morning says a bump means a change made during the
build week. Reading the ETHGlobal dashboard changed Tier 1, the prize requirement, the
submission deadline, the judging shape and the protocol-fee position. That is exactly the
kind of change the rule was written for.

**Consequences.** CLAUDE.md, `architecture.md` and `links.md` point at v2. Anything that
still cites v1 is stale. v1 remains readable for anyone tracing why a decision was made.
