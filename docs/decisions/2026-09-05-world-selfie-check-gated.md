# World Selfie Check: option bought, build gated on x402

**Decision.** Sandbox access has been requested, which costs nothing and buys an option
because the approval queue is the long pole. **Nothing gets built until the x402 gate is
green.** The go or no-go is taken on **Wed Sep 9**, at the recording milestone, by Nasaa
under scope-cut authority. If x402 is not done or the clean testnet run does not exist,
this is dropped without regret.

**Why it is worth an option at all.** The prize page's second qualification requirement is
that Selfie Check be treated as a risk, eligibility, fairness, continuity or
abuse-prevention signal. Gating who may claim an order and sign an attestation is exactly
that, so the fit is genuine rather than prize-chasing. The brief already made room for it:
World ID for personhood, as a registry tag type distinct from a professional credential,
because personhood is not a qualification. No design change is needed to accommodate it.

**Where it would go: sign time, not claim time.** The attestation is the artifact that has
to be backed by a live human, so the check binds to the moment of signing. That is the
strongest version and a one-screen addition to a workflow P3 is already building.

**What it does not do, and this is the part that matters.** Selfie Check proves a live
human was present. It does **not** prove that human read the artifact. It kills the bot
rubber-stamp and leaves the lazy-human rubber-stamp entirely intact.

If we ship it, the Known Limit changes from "a script can farm this" to "a human can farm
this". That is a real but partial improvement. **Claiming it closes the disputes gap would
break our own honesty rules on camera**, and a judge who knows World's stack will catch
it. m-of-n jury plus bonds remains the production answer.

**The economics, corrected.** The prize page says up to three teams at $1,166 each, not
$3,500 to one team as the Discord announcement read. AgentKit Continuity is
Continuity-track only and therefore unavailable to us, so it is not a consideration.

**One requirement plays to our strength.** A feedback document covering the docs, the
developer portal and the sandbox is a qualification requirement rather than a bonus. Most
teams will skip or half-do it. We write research notes as a habit.

**Consequences.**

- Amends the brief's Tier 3 line, which said World ID is never built this week. It is now
  Tier 3 **until** the Sep 9 gate, and Tier 2 only if that gate passes.
- No build issues exist on the board on purpose. A gated decision issue exists instead,
  because an issue titled "integrate Selfie Check" reads as permission to start.
- World documentation stays out of the shared notebook until the gate passes, so the
  notebook keeps answering Hedera and x402 questions rather than diluting.
- Before Sep 9, somebody spends twenty minutes on the integration doc and writes a
  two-line size estimate into the gate issue, so the decision is informed rather than a
  guess.
